# Java Parameterized Constructor

## Description
This Java program demonstrates the concept of a parameterized constructor. It accepts a student's roll number as input, initializes the `Student` object using a constructor, and displays the roll number.

## Concepts Used
- Java Classes and Objects
- Parameterized Constructor
- Scanner Class
- User Input and Output

## Sample Input
```text
101
```

## Sample Output
```text
Roll No: 101
```

## How to Run
1. Save the program as `Student1.java`.
2. Compile using `javac Student1.java`.
3. Run using `java Student1`.
4. Enter the student's roll number.

## Language
Java
